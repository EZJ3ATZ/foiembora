FoiEmbora

Política de Privacidade

Última atualização: 28 de maio de 2026

✓ Sem senha · Sem risco de ban

O FoiEmbora é uma plataforma que permite monitorar seguidores do Instagram usando a sessão autenticada do próprio usuário, sem armazenar senhas. Esta política descreve quais dados coletamos, como os usamos e como os protegemos.

1. Dados coletados

A extensão do FoiEmbora coleta os seguintes dados por meio da sessão autenticada do usuário no Instagram:

  • Lista de usuários que o usuário segue (following)
  • Lista de seguidores do usuário (followers)
  • Informações públicas de perfis monitorados (nome, username, contagem de seguidores)

Do usuário da plataforma, coletamos:

  • Endereço de e-mail (para criar e identificar a conta)
  • Token de acesso gerado pela plataforma (armazenado localmente na extensão)

Não coletamos e não armazenamos senhas do Instagram.

2. Como usamos os dados

Os dados coletados são usados exclusivamente para:

  • Comparar snapshots de seguidores e identificar quem parou de te seguir ou quem é novo
  • Rastrear mudanças em perfis públicos monitorados pelo usuário
  • Manter o histórico de análises associado à conta do usuário

Não usamos os dados para fins de publicidade, perfilagem, crédito ou qualquer finalidade não relacionada ao monitoramento de seguidores.

3. Compartilhamento de dados

Não vendemos, alugamos nem transferimos dados dos usuários a terceiros. Os dados são armazenados em servidores próprios (Railway) e não são compartilhados com nenhuma outra empresa ou serviço.

4. Retenção de dados

Os dados de rastreamento (snapshots de seguidores) ficam disponíveis durante o período de assinatura ativa. Se a assinatura expirar e não for renovada, todos os dados associados à conta são excluídos automaticamente. O usuário também pode solicitar a exclusão a qualquer momento pelo suporte.

5. Permissões da extensão

A extensão do FoiEmbora solicita as seguintes permissões e as usa exclusivamente para:

  • activeTab: Acessar a aba do Instagram aberta para coletar dados de seguidores via sessão autenticada
  • tabs: Identificar qual aba está com o Instagram aberto
  • storage: Armazenar localmente o token de acesso do usuário
  • scripting: Injetar o script de análise na aba do Instagram

A extensão não acessa dados de outros sites ou abas não relacionadas ao Instagram ou ao FoiEmbora.

6. Segurança

Os dados são transmitidos via HTTPS. O token de acesso armazenado na extensão é único por usuário e pode ser revogado a qualquer momento pelo suporte. Nenhuma senha do Instagram é armazenada em qualquer momento.

7. Direitos do usuário

O usuário pode a qualquer momento:

  • Solicitar a exclusão de todos os seus dados
  • Solicitar uma cópia dos dados armazenados
  • Revogar o acesso da extensão removendo-a do navegador

Para exercer esses direitos, entre em contato pelo e-mail: suporte@foiembora.com.br
