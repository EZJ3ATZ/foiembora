Diferencial Técnico

Por que não causa banimento

🏠
IP residencial do usuário
Todos os requests saem do computador do usuário — não de servidores nossos. Instagram vê um acesso normal.
🔬
TLS fingerprint real
Extensão roda no Chrome real — fingerprint idêntico ao de um usuário humano navegando normalmente.
👁️
Somente leitura
Nenhuma ação automatizada. Não segue, não deixa de seguir, não curte — só lê dados que já aparecem na tela.
⏱️
Velocidade humana
Intervalo de 600ms entre requisições — padrão de um humano navegando. Abaixo do threshold de detecção.

🔴 IP de datacenter → ban imediato
🔴 Pedem senha → risco de sequestro
🔴 TLS de Python → flagado pelo Instagram
